# SITE ATTENDANCE — V1

A GitHub Pages-friendly prototype for a site attendance and fingerprint management system.

## V1 includes
- Professional animated login page
- Accountant portal
- Employee portal
- Role-based demo routing
- Excel fingerprint import using SheetJS
- Employee data import from the workbook
- First/last fingerprint logic
- Missing fingerprint detection
- Accountant-review flag for days with no fingerprints
- Friday special handling
- Working schedules and ±60 minute overtime cap
- Monthly employee reports
- Responsive design

This V1 is a front-end prototype. Credentials are not secure because GitHub Pages is static. Do not use real employee credentials or sensitive data until a backend/authentication layer is added.

## GitHub Pages
Upload the entire folder to a repository and enable:
Settings → Pages → Deploy from branch → main → /root

The entry point is `index.html`.
